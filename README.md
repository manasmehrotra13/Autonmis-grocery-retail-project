# Grocery Retail: Data Warehouse and Strategic Analysis

Project from my data analyst internship at Autonmis (2025). The data is made up (generated), so it can be shared.

**What I did:** designed a data warehouse for a grocery business (13 fact and 13 dimension tables), generated realistic data with seasonality, missing values, duplicates and late-arriving rows, moved it from PostgreSQL to Snowflake, and built a sales dashboard on top.

**Files:** `latestretail.ipynb` (the Python notebook), the data model (PDF and text), the transformation notes, the dashboard and the write-up (PDFs), the datasets (zip).

*Note: the product and category names are generated placeholder text.*
